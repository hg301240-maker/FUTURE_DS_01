# 📊 Sales Performance Analysis Dashboard – Excel

## 📌 Project Overview

This project is an **Excel-based Sales Performance Analysis Dashboard** created to analyze sales data and identify important business insights.

The project uses raw sales data, Pivot Tables, charts, and KPI analysis to understand **sales performance, monthly trends, product performance, category-wise sales, and regional performance**.

The dashboard converts raw business data into an easy-to-understand visual report that can help in monitoring sales performance and making data-driven business decisions.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze overall sales performance.
* Identify monthly sales trends.
* Find the top-performing products.
* Compare sales across different product categories.
* Analyze regional sales performance.
* Identify the best-performing month.
* Identify the highest-performing category.
* Present important KPIs and business insights through a dashboard.
* Provide recommendations based on the analysis.

## 📑 Excel Workbook Structure

The workbook is divided into four main sheets:

### 1. Raw Data

Contains the original sales transaction data used for analysis.

It includes customer, order, product, sales, quantity, discount, profit, category, and regional information.

### 2. Pivot Analysis

Contains Pivot Table-based analysis for:

* Monthly Sales Trends
* Top 5 Products by Sales
* Category-Wise Sales
* Region-Wise Performance

Pivot Tables were used to summarize the raw data and identify important patterns.

### 3. Dashboard

Provides a visual representation of the analyzed sales data using charts and dashboard elements.

The dashboard helps users quickly understand the overall sales performance and major trends.

### 4. KPI Dashboard

Contains important business insights, key metrics, and recommendations based on the analysis.
